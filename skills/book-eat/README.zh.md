# book-eat（中文说明）

**AI 替你吃书，你消费知识。**

生态里的"读书"skill 多是陪读教练——你自己读章节，AI 出题考核你。book-eat 反过来：agent 读完整本书（PDF/EPUB，扫描件或文字层皆可），替你建一座**带页码出处的永久知识库**。你靠分层笔记掌握全书，需要核对时才回原文。

六步流水线，状态机可重入（中途丢给它，从断点续跑）：①全文缓存（文字层秒抽/扫描件本地 OCR，不上传外部服务）→ ②定纲分级（**确认门必停**，分级是编辑判断，错了全废）→ ③分层精读（精读/摘要，条条带书+页出处）→ ④归档（主题笔记/术语回填/⚠未验证升级）→ ⑤复习卡片（Q/A+出处+难度+状态）→ ⑥看板。质量门：引文/考据数据/表格图版回原图核对（无视觉工具则出 ⚠待人工复核清单，绝不静默跳过）。OCR 缓存是不可变的原始层，修订只落笔记层，全程可审计。

## 安装

```bash
npx skills add MerliniKing/book-eat@book-eat
```

依赖：Python 3 + `pymupdf`（必备）+ `rapidocr-onnxruntime`（扫描件才需要），缺失时 skill 自动补装。

## 快速开始

新书放进 `sources/`，对 agent 说"**吃这本书**"。首次运行自动自举建库（sources/books/cards/topics/INDEX.md），缓存全文后在定纲确认门停下等你。

## 为什么不直接让模型总结？

一次性总结把书压成一个无出处的观点，且无法回查。book-eat 给的是**分层**：摘要层快速抓骨架，精读层吃透核心，全文缓存层随时回原页对质——这是你期望研究助理替你读书的方式：带收据。
