# 微信公众号适配

status: 默认模板（未按个人样本定制）

- 篇幅：1500-3000 字为主。
- 标题：有具体信息量，不玩空悬念；给用户备 3 个候选标题。
- 开头：前 3 行决定完读率。用场景、具体事件或反常识结论切入；禁"随着……的发展"，禁"你是否也……"式空问。
- 结构：小标题下直接进实质内容，禁止第一句复述小标题；段落 3-5 行，手机上一屏最多两段。
- 结尾：落在最后一个具体事实或一句收敛的观点上；互动引导最多一句，不写"点赞在看转发"三连。
- 排版：文字定稿后如需转公众号 HTML，交给 md-to-wechat。
