# 写作硬规则

## 基础规则（内置，去 AI 味底线）

完整检查表在 skill 程序目录的 `references/ai-tells-zh.md`，以下是最容易踩、必须守的几条：

1. 段落开头不堆连接词：此外 / 另外 / 与此同时 / 值得注意的是 / 综上所述，一段最多留一个连接词，能删则删。
2. 禁否定式排比：「不是X，而是Y」「不仅仅是X，更是Y」。
3. 禁强制三连排比；列举两项或四项更自然。
4. 禁句尾升华：「……，彰显着……」「……，见证着……」「……，诠释着……」，事实说完就停。
5. 破折号（——）全篇不超过 2 处；用户声纹显示爱用则按声纹来。
6. 结尾不展望、不升华、不喊口号，落在最后一个具体事实上。
7. 模糊归因（"专家表示""业内人士认为"）必须有真实来源，否则删掉论断。
8. 不编造事实、数据、引用、截图；素材不足就问用户，不猜。
